#  Dashboard de Análise de Salários (Área de Dados)

Este projeto foi apresentado durante a **Imersão Dados da Alura**. A aplicação foi montada por mim utilizando os códigos e a base de dados disponibilizados pelos instrutores da imersão para fins de aprendizado prático.

O foco desta etapa foi realizar o **deploy** da aplicação, conectando o código via GitHub ao Streamlit Cloud para publicação do dashboard online.

## Funcionalidades do Dashboard
* **Filtros Interativos:** Permite explorar dados por Ano, Senioridade, Tipo de Contrato e Tamanho da Empresa.
* **Métricas (KPIs):** Visualização de salário médio, salário máximo e cargo mais frequente.
* **Visualizações Dinâmicas:** Gráficos de barras, histogramas, mapas de calor e proporção de modelos de trabalho.

## Tecnologias e Ferramentas
* **Python**: Linguagem utilizada nos scripts.
* **Streamlit**: Plataforma de hospedagem e interface.
* **GitHub**: Controle de versão e repositório dos arquivos.
* **Código e Dados**: Providos pela equipe pedagógica da Alura.
